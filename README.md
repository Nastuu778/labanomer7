**DUPLICATE FINDER** - утилита для поиска дубликатов файлов на основе их размера и хеша содержимого.

**Поддерживаемые параметры командной строки**
Программа принимает следующие аргументы:

1. -d или --dir — обязательный параметр, указывает входную директорию. Можно указать несколько раз для обработки нескольких путей.
2. -e или --exclude — префикс имён файлов, которые следует игнорировать (например, -e . исключит все файлы, начинающиеся с точки, вроде .gitignore).
3. --depth — максимальная глубина рекурсивного обхода каталогов. Значение -1 означает неограниченную глубину (по умолчанию).
4. -b или --block-size — размер блока (в байтах), с которым читаются файлы при хешировании. По умолчанию — 65536 (64 КБ).
5. --hash — в текущей версии является заглушкой.

# Программа не поддерживает маски файлов (например, *.txt). Вместо этого используется внутренний хеш на основе boost::hash_combine.

**Установка BOOST**

Я работаю через Powershell, так что команды будут соответствующие
Для начала проверим в каком окружении мы работаем чтобы установить туда boost
Выполняем команду - Get-Command g++ -ErrorAction SilentlyContinue
Получает окружение (у меня например ucrt64) и туда устанавливаем boost
Переходим в нуженый нам терминал (у меня например msys2 ucrt64) и устанавливаем boost командой 
pacman -S mingw-w64-x86_64-boost

**Принцип работы**
1. Сбор файлов: рекурсивный обход указанных директорий с учётом глубины и префикса исключения.
2. Фильтрация: пропускаются файлы, чьё имя начинается с exclude.
3. Группировка по размеру: только файлы одинакового размера сравниваются дальше.
4. Хеширование: файл читается блоками; хеш строится через boost::hash_combine.
5. Вывод: группы файлов с одинаковым хешем печатаются как дубликаты.
